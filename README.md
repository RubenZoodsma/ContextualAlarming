# ContextualAlarming

Analytic code for the manuscript:

> **Variation in Medical Device Alarm Streams Across Patient Contexts in Pediatric and Neonatal Intensive Care: A two-year observational study**
> R. S. Zoodsma, E. Koomen, L. van Loon, I. Boelhouwer, D. Vijlbrief, J. Nijman, T. Kappen
> Wilhelmina Children's Hospital / University Medical Center Utrecht, the Netherlands

The R scripts in `Analytics/` produce the tables, figures and appendices of the manuscript from the preprocessed study dataset.

```
Analytics/
├── primaryAnalysis/    Tables 1–3, Figures 1–2
├── appendixAnalysis/   Appendices
└── supplAnalysis/      Appendix III, supplementary analysis
```

## Data availability

The alarm data and patient-level information cannot be shared because of confidentiality restrictions; the scripts therefore cannot be run without them. Reasonable requests for access can be sent to the corresponding author.
